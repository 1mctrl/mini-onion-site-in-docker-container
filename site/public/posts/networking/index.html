Часть 1.3: Диапазоны и сегменты сетей

  • Частные (private) диапазоны IPv4, которые никогда не бывают публичными:

    • 10.0.0.0 – 10.255.255.255
    • 172.16.0.0 – 172.31.255.255
    • 192.168.0.0 – 192.168.255.255

  • Теперь по адресам которые даны:

    • Частные IP
      Их можно использовать только внутри локальных сетей:
      • 10.0.0.45 — private
      • 192.168.4.2 — private
      • 172.20.250.4 — private
      • 172.16.255.255 — private
      • 10.10.10.10 — private
    • Публичные IP
      • 134.43.0.2 — public
      • 172.0.2.1 — public (да, 172.* не значит автоматически private, сюрприз)
      • 192.172.0.1 — public
      • 172.68.0.2 — public
      • 192.169.168.1 — public
