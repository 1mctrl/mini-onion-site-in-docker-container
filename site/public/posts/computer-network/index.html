Компьютерные сети и телекомуникационные технологии: элементы и структуры

  1. Системы коллективной деятельности опирающиеся на телекомуникационные технологии разделяется на две 2 группы:

    • системы с разделением времени (Time sharing system)
    • системы обеспечения групповых решений (Computer supported cooperative work, groupware)

  2. Этапы развития инфраструктур коллективной информационной деятельности можно рассматривать как эволюцию средств связи и взаимодействия:

    • Локальный хост (localhost)

    • Локальная сеть (local area network)

    • Глобальная сеть (Global network)

    • Интернет (Internet)

  3. Архитектура клиент-сервер:
    (client-server model)

    Система Клиент Сервер
    Вычислительная сеть Рабочая станция, thin client Сервер приложений / вычислительный кластер
    Локальная сеть (файл-сервер) ПК пользователя (Windows, macOS, Linux) NAS / файловый сервер (Samba, NFS)
    Удалённый доступ SSH-клиент, RDP-клиент SSH-сервер, RDP-сервер
    Клиент–серверные ОС Пользовательские процессы Ядро ОС / системные службы
    FTP / SFTP FTP/SFTP-клиент (FileZilla, WinSCP) FTP/SFTP-сервер (vsftpd, OpenSSH)
    Электронная почта Почтовые клиенты (Outlook, Thunderbird, WebMail) Почтовые серверы (Postfix, Exim, Exchange)
    WWW / Web-приложения Web-браузеры (Chrome, Firefox, Edge, Safari) Web-серверы (Nginx, Apache, IIS)
    API / микросервисы HTTP-клиенты, frontend-приложения REST / GraphQL / gRPC-сервисы
    Облачные сервисы Web / мобильные клиенты Облачные платформы (AWS, Azure, GCP)
    Контейнерная инфраструктура CLI, Web UI, CI/CD Kubernetes, Docker, сервисы оркестрации
    Системы обмена сообщениями Producer / Consumer Message broker (Kafka, RabbitMQ, Redis)
