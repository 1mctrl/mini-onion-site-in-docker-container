Расчёт IP-адресов и подсетей

1. Перевод IPv4-адресов в бинарную нотацию

IP-адрес: 178.101.89.7

lpad(string(178, base=2), 8, '0')
# "10110010"

lpad(string(101, base=2), 8, '0')
# "01100101"

lpad(string(89, base=2), 8, '0')
# "01011001"

lpad(string(7, base=2), 8, '0')
# "00000111"

Результат:

10110010.01100101.01011001.00000111

IP-адрес: 201.57.153.161

lpad(string(201, base=2), 8, '0')
# "11001001"

lpad(string(57, base=2), 8, '0')
# "00111001"

lpad(string(153, base=2), 8, '0')
# "10011001"

lpad(string(161, base=2), 8, '0')
# "10100001"

Результат:

11001001.00111001.10011001.10100001

2. Расчёт подсетей для сегментов организации N

Методика расчёта

Количество бит под хосты (h) выбирается так, чтобы выполнялось условие:

2^h − 2 ≥ количество_хостов

Маска сети определяется по формуле:

CIDR = 32 − h

Учитывается, что:

  • первый адрес подсети — адрес сети;
  • последний адрес — широковещательный (broadcast).

Технологический сегмент

Требуемое количество хостов: 3

begin
    hosts = 3
    h = 1
    while 2^h - 2 < hosts
        h += 1
    end
    network_mask = 32 - h
    println("CIDR для технологического сегмента: /$network_mask, хостов: $(2^h - 2)")
end

Результат:

CIDR: /29
Доступно хостов: 6
